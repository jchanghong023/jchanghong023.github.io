# JchTools 有哪些功能 {#features}

Windows 本地工具箱。[下载安装包或便携版](https://github.com/jchanghong023/JchTools/releases)。

在黄区配合 OMP 使用 CodeAgent，见[下载与使用步骤](/omp/codeagent)。

| 功能        | 能做什么                                                          |
| ----------- | ----------------------------------------------------------------- |
| 递归解压    | 解开压缩包，以及压缩包里的内层包。                                |
| 目录整理    | 分析目录、去重、按文件类型归类、清理空目录。                      |
| MD 整理     | 合并 Markdown，或按大小拆分 Markdown 文件。                       |
| 转 Markdown | 将 Office、PDF、图片等转成 Markdown；音视频转写需要额外音频组件。 |
| Git 工具    | 将改动按文件逐个提交并推送。                                      |
| 截图 OCR    | 框选屏幕提取文字；也提供 `jchocr` 图片识别命令。                  |
| 模型服务    | 将外部 ACP Agent 接入为本机 HTTP 模型接口。                       |
| CodeAgent   | 自动维护当前用户已登录 CodeAgent 的本地 Token。                   |

**先用副本试运行：递归解压成功后会删除源压缩包；目录整理会永久删除重复副本，不经过回收站。**

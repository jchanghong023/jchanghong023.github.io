# 共享 Xberg、设置与后台服务 {#xberg-inference}

Xberg 承接文档解析、图片/截图 OCR 与媒体转录。JchTools 保留页面、任务、托盘、热键、框选与结果窗。**共享的是引擎和配置入口，不是把几个工具自动串联**；模型服务 ACP 和 CodeAgent 是另外的后台。

## 各场景职责与模型隔离 {#responsibilities}

XB-01～XB-04：文档使用 tiny；截图使用固定 medium 检测、TextSnap small 识别与原字典，名称相似不意味着可混用或回退；媒体使用既定 Silero VAD + SenseVoice 链路。截图瓦片/布局、转录术语仍按各自域要求，不因引擎升级擅改。

全部推理走本地进程通信，不增加网络监听。截图图像、音频解码数据和正文不应落盘/上传/进日志；转换最终结果按用户指定位置保存。当前媒体实现的读取/临时副本缺口见[媒体真实限制](./all2markdown#media-limits)，不能把需求隐私边界当现状已验证。源文引用的 SNAP-02～SNAP-06 是上游场景分离关联，不是 JchTools 新增用户功能。

## 本地协议、错误与取消 {#protocol}

XB-05～XB-08：唯一 `xberg worker` 使用 stdio JSON 行请求响应，截图送内存无损图像 Base64，文档/转录送路径；每请求一行响应并明确归属。文档 extract 只传 path，不传 mode/模型/请求级转换配置；最终 `document.content` 是引擎 Markdown，warnings 对应 processing_warnings，JchTools 只处理媒体目录前缀和字节落盘，不二次分节/去重/规范化。

场景能力与独立配置显式声明，截图模型集名为 `snapshot-pp-ocrv6-medium-det-textsnap`；错配报错，不另开引擎补救。错误至少区别资产未就绪、校验/模型错配、解码、无文字/无音轨/无语音、超时、取消、内部错误。

正常取消/超时按请求隔离：截图在不可中断调用返回的瓦片/批次检查点取消；转换尽快结束当前文件不等整个文件自然完成，不启下一文件。不能关共享连接、杀引擎或卸载另一场景模型。引擎自身崩溃时受影响任务失败，不自动重放。

## 随包版本与音频下载 {#delivery}

XB-09～XB-13：打包应取当时最新 Xberg 正式发布，锁精确 tag、来源、大小和 SHA-256，校验归档和成员、保留许可。获取最新失败不能偷偷选旧。安装后使用包内锁定版本，不在启动、切页、截图或转换时查最新/自动更新。

运行目录就绪只核对本场景成员存在及协议能力，不以大小/摘要/版本不同拒绝用户兼容替换。成员缺失/加载失败/能力不满足明确报错，不混多个目录或模型；基础缺损修复安装/重装/重新解包，音频缺项才提示设置主动下载。

两种分发等价，基础资产完整随包；不把上游独立功能 ZIP 的数量/布局变成用户要分别初始化组件的义务。FFmpeg 与必要 DLL/许可、SenseVoice INT8、Silero VAD 与配套数据仅按**包内引擎清单匹配版本**主动下载到同一目录。已校验有效成员复用，不重下，不为了追新替换已有有效引擎和共享 DLL；失败/取消不覆盖有效配置/资产，不删除旧目录。

独立媒体 worker 与截图内部重复 det/rec 推理应退役，但保留托盘、字体、用户设置与自启。退役前同批公开合成样本对照文本/布局/时间戳/耗时/内存，旧成功记录不替迁移后证据。包内引擎交付验收与“另取当前最新正式版对照”是两件事，后者不能代替实际包测试。

## 设置页怎么用 {#settings}

XB-19、XB-20：打开独立「设置」，查看当前共享运行目录与包内来源，以及：

- 文档/图片、截图的随包就绪、缺失或不兼容状态。
- FFmpeg/配套运行库与音频模型各自未下载、下载中、就绪或失败状态。
- 离线检查、基础组件修复指引；音频主动下载、进度、取消、失败原因与重试。
- 截图登录自启、模型重试与故障恢复等应用级入口。

没有手填/选择运行目录、三功能多选、截图/文档下载或首次只勾截图流程。下载不应阻断其他在途任务，不以取消下载/关闭功能删有效资产。缺 FFmpeg 或音频模型只使媒体未就绪，不能阻止 worker、截图、文档/图片、jchocr 或旧工具。

音频下载网络遵守 Windows 手动代理与一次直连回退；PAC/WPAD 不支持。现行 P-09 下载器跳过 HTTPS 服务端证书信任链/域名/有效期检查，不保证服务器身份，进度应明确提示，仍保留 TLS 加密/握手签名和文件摘要。不要把此策略用于 Git 或其他网络入口。

## 一个引擎，场景可以并用 {#shared-process}

XB-14～XB-17、5.1：同一 Windows 用户会话至多一个活动 Xberg，不按文件、功能、模型、配置或预检另开进程；GUI 与截图托盘进程可以独立。文档当前文件处理中，截图仍应由同一引擎返回，而不是排到整份文档结束后或重启转换切场景。

转换文件之间严格串行，截图请求之间单任务；两者不是跨场景互斥。各场景模型/字典/阈值/线程/快速模式分开持有并复用，截图和文档模型可同时驻留，不随另一场景请求反复重载。CPU/内存竞争如实反映，不承诺零性能代价。

取消截图不影响转换；转换停止/超时不影响截图，不靠杀引擎实现。只有用户托盘明确全部后台退出、安全结束所有任务后，才终止应用拥有的 Xberg。引擎异常恢复仍保持单例且不重放失败任务。

## SQLite、旧配置与安全迁移 {#persistence}

XB-18、XB-21：应用状态目录的 SQLite 是唯一共享配置所有者。新装/便携首次无数据库、旧目录、缓存或功能勾选时，自动发现包内目录并建立配置；保存立即落盘，新进程/重启恢复，不能靠同进程缓存冒称持久化。已有数据库读写失败需提示，不能用默认空值覆盖有效设置；原文件工具会话规则不因此持久化。

升级读取旧文本/SQLite 有效来源，**迁移未成功保存并在安全边界统一切换前，截图、文档、jchocr、媒体均继续用旧有效目录**，不各自抢用包内目录或多开引擎。

迁移不整体复制旧树、不改写/删除源文件，只只读核对并复制匹配目标引擎清单的音频可选成员与许可，复用有效目标，不覆盖引擎/已有共享 DLL，不复制无关用户资料。旧源媒体完整就绪时，要目标基础可用、兼容媒体复用/迁入/验证、媒体能力继续可用且配置保存成功后才统一切换。

迁入、校验、保存失败或无法确认兼容时保留旧有效目录、配置与能力，说明原因，不静默禁用媒体/联网补齐。旧环境只有部分音频成员时复用有效部分；未下载音频不是基础发现/迁移前置条件。失效旧目录不应阻止新装式包内发现，也不能成为基础缺损时的隐式回退。

## GUI 关闭不等于后台退出 {#lifecycle}

XB-22～XB-25、7.1：先显示可交互 GUI，再异步发现/读配置、检查、自动连接或保活截图与共享引擎，不要求先进入截图页。关闭或终止 GUI 后服务/热键/托盘/截图继续；重开连接原实例。登录自启仍默认关。

统一托盘可开主界面/设置/截图，用“退出后台服务”主动退出；有任务先提示确认、停止接新任务并安全收尾，不自动强杀，不操作用户自行启动的 Xberg。退出后当前已开 GUI 不立即拉回后台，下次重开才自动启动。截图页只留热键设置与状态，没有常规启停/重连/截图按钮。

文档转换、解压、整理、MD、Git 的在途任务仍由主窗口管理：关窗需确认安全停止，不因后台保活变成关窗继续执行。模型服务独立退出按 AH-10，不归截图托盘；CodeAgent 同样另有所有者。

## 用户替换组件的边界 {#replacement}

XB-26：允许在**当前生效目录内**替换兼容引擎文件，不必自行维护成员摘要；设置页不因此提供换目录入口。正常替换也需协议/成员存在，失败明确提示，不自动降级或切源，不解除一个引擎和模型分离约束。不要在在途任务中修改文件；处理期外部改动不是受保护场景。

这不改变组包/主动下载完整性校验，也不授权下载覆盖有效引擎。替换后实际转换/截图的真实证据另记来源，不能替代未修改包内资产的交付验收。

## 基础资产和可选资产清单 {#asset-boundary}

XB-27：主包必需包含唯一引擎、截图/文档独立模型与字典、所需 DLL/原生库（含 sherpa-onnx、共享 ONNX Runtime）、字体和许可。默认不含 FFmpeg 及其音频专用配套库/许可，也不压进 EXE；本次新增可选运行依赖只 FFmpeg，不借此移走 OCR 所需共享库。

音频可选资产仍装当前同目录，路径安全检查、归档/成员大小摘要、事务保护都保留；取消/失败不覆盖有效配置或资产、不删未涉及资料。尚未准备时处理媒体只提示，不静默下载。所谓会议/录音仅既有音轨转写，不提供录音、会议或画面理解。

## 验收需要哪些真实证据 {#acceptance}

5.2 需要 UT/集成证明请求归属、同时启动单引擎、取消隔离；还需真实 GUI 长文档未完成时完成热键/托盘 OCR 与复制，同时验证正文/产物正确、同 PID、模型加载次数，而不只检查窗口没卡。先截图/先文档/同时启用、重复请求、模型驻留、单场景退出、引擎异常均须观察。

第 6 节与 7.2 需要两种实际分发的新装无旧数据/无音频时基础可用、保存后新进程和重启恢复、完整/部分旧音频迁移、迁入/验证/保存失败保护及源目录不变。完整旧媒体就绪须迁移后真实转录，不以文件存在替代；音频主动下载进度、取消、重试、既有资产复用与隐私也要覆盖。

8.1 需要替换兼容文件后真实转换/截图仍单引擎且模型不混，与原包交付验收分开记录。模拟引擎、Slint 测试后端、旧迁移结果或最新发布对照仅补充，不能当所有真实边界通过。本次网站工作未执行任何产品验收，具体包的未验证项应保留而不是用来源覆盖表消除。

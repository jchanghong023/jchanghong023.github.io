# 截图 OCR 与 jchocr {#snap2text}

截图 OCR 把框选区域变为尽量保持二维位置的**纯文本**，不是 Markdown、翻译、润色或截图历史工具。jchocr 则把同一截图模型与布局通道提供给程序和 Agent，一次识别一张图片，不打开 GUI。

## 支持环境与独立性 {#scope}

O-01～O-04：截图场景为 Windows 11 x64、CPU/AVX2，不要求 GPU；不支持 Linux、ARM、UAC 安全桌面、受保护视频或 DRM 表面，不承诺系统不提供的图像。其他工具不因此新增平台限制。

截图和文档转换共用同一 Xberg，但模型、配置、取消各自独立；截图服务失败不能阻止其他工具，未下载 FFmpeg/音频模型不影响基础 OCR 或进程启动。业务使用 Rust/Slint 与必要原生接口，无旧 Python、PySide6 或 PaddleOCR Python 运行依赖；内部协议不是用户 CLI。

## 随包资产与固定模型 {#assets}

O-05～O-10：两种分发均应带截图服务、Xberg、截图与文档各自独立模型/字典、必要 DLL、许可；Noto Sans Mono CJK SC Regular 和 OFL 内置截图服务，无需系统装字体或额外初始化。自动发现共享目录，不要求下载基础组件、手填路径或旧缓存；缺损走安装包修复/重装或便携重新解包，不能静默降级字体/切目录/改模型。

当前源需求固定截图 **PP-OCRv6 medium FP32 检测 + TextSnap small FP32 识别**，文档仍是 tiny。识别字典 18708 字有序，CTC 18710 类为 blank、原字典、尾空格，不能重排/去重/混字典/量化替换。模型是从 Paddle 权重转换的固定派生 ONNX，不冒称官方原生 ONNX，也不要求用户安装转换工具。

附录 A 的身份基准来自 Xberg `v2026.10.17-060616-local.841f1fe8d8`；这指当前需求，不保证早于该时间的公开 JchTools 包已经带入。

## 第一次热键截图 {#workflow}

1. 打开 JchTools，先等待后台状态从检查/加载进入就绪。窗口应先可用，模型异步加载。
2. 截图页只设置快捷键与看服务状态；默认 **Ctrl+Alt+O**。实际截图用热键或托盘「截图识别」，页面没有常规启停或截图按钮。
3. 把鼠标放到目标显示器后触发，应用相关窗口先隐藏，抓该屏物理像素并冻结，不含鼠标指针、不能跨屏框选。
4. 在冻结图上任意方向拖选，松左键提交。Esc/右键或任一边小于 8 像素均取消；背景后续变化不影响已冻结图。
5. 识别中可取消；再次热键只提示“正在识别”，不排队、不抢掉当前任务。取消在不可中断调用返回后的瓦片/识别批次边界生效，不伪造百分比。

O-17～O-20：无文字、截图失败、OCR 失败分开提示，不开空结果窗。新任务前旧结果仅内存暂存并隐藏，新任务取消/失败/无字恢复旧结果，只有成功才替换。

## 结果窗和复制 {#result-window}

O-21、O-22：结果窗位于截图屏幕工作区中央，初始约 80% 大小，显示时激活但不永久置顶；只读、内置等宽中日韩字体 12pt、不自动折行，横纵滚动。调整窗口不改变真实换行、缩进或内部空格。

可以选择文本、右键复制、Ctrl+C、Ctrl+A 或“复制全部”。局部复制/Ctrl+C 不自动关窗，“复制全部”后关闭。复制的是布局原文，不二次排版；关结果窗清文字引用但不停止后台。输出近似二维普通文本，不还原原 Tab、字体大小、表格线、HTML 或交互。

## 托盘、热键与关窗 {#background}

O-11～O-16：截图是当前登录用户独立后台，不是管理员 Windows 服务。打开 GUI 自动连接/启动单实例，关闭或终止 GUI 不取消 OCR、不卸载模型、不移除托盘/热键；重开接同一实例，不加载第二套模型。

首次正常启动提示当前真实热键；登录自启启动不再弹首次通知。托盘提供主界面、截图、设置、开机启动、退出后台服务；品牌图标随程序内置。自启默认关，只管理当前用户本功能项；移动/删除前先关闭自启，启用后路径改变重新运行更新自己的项。

修改热键先成功注册新组合再释放旧组合，冲突保留旧值并提示，未确认不冒称生效。加载状态区分未加载/加载中/就绪/错误，允许等待，失败有设置页重试，不联网。截图设置保存才持久化，损坏用内存默认并提示，不静默覆盖原文件；Xberg 与音频状态统一 SQLite，不开放 OCR 阈值或旧三功能勾选。

完全退出截图/Xberg 用托盘明确退出，先确认、拒新任务并安全停止已有任务。识别超过 10 秒才可提供显式强制退出，不能自动强杀，仍不得杀有其他任务的共享 Xberg。截图退出与模型服务/CodeAgent 的生命周期不是同一个开关。

## jchocr：给程序调用的图片接口 {#jchocr}

O-33～O-37：安装包把 `jchocr.exe` 复制到当前用户原有 PATH 的 WindowsApps，不修改用户/系统 PATH、不需管理员；便携包只随附命令，在其目录用 `./` 或显式路径调用。命令自动发现同一生效共享目录，不需先开 GUI、创建 SQLite、配置环境变量或下载音频模型；安装版从其他当前目录也应定位正确。已有旧有效来源迁移未完成时仍共同读取旧源，不由 CLI 自行改配置。

输入互斥：一个本地绝对路径或 HTTP(S) URL；`--stdin` 原始图片字节；`--base64 <值>`；或 `--base64 -` 从 stdin 读 Base64。一次一张，不新增 MCP/HTTP。可先看无需 Xberg 即可显示的帮助：

```powershell
jchocr --help
jchocr --version
```

便携包内对应命令是 `./jchocr.exe --help`。本地文件只读；URL 仅下载显式图片及 HTTP(S) 重定向，系统代理按既有约定，不接受其他协议，图片只在内存。不任意添加更小文件/像素上限，但不得超过现有代理消息容量（含 Base64 扩张与元数据）；超容量停止下载并失败，不截断后继续识别。

默认 stdout 仅 UTF-8 布局正文，保留空格和换行；`--json` 成功为 `{"ok":true,"text":"..."}`。无字是成功空正文；失败不输出伪正文，错误到 stderr，JSON 错误结构含 `ok:false`、`error_kind`、`error`。

| 退出码 | 含义                           |
| ------ | ------------------------------ |
| 0      | 成功，含无文字                 |
| 2      | 参数/输入错误                  |
| 3      | 生效目录无法定位或必需资产缺失 |
| 1      | 下载、推理或运行错误           |

缺损资产提示修复安装/重装/重新解包，不让调用方维护 JSONL、请求 ID、worker 生命周期或先下载 Xberg。具体支持图片格式以随包 `--help` 与引擎能力为准，不把文档转换所有格式当图片输入。

## 隐私和资源边界 {#privacy}

O-29～O-32：截图/裁剪图/进程间图像/文字和临时结果只驻内存，不自动保存历史、数据库、临时图片、错误正文或网络上传；任务结束/取消释放图像，结果窗关闭清正文。模型常驻不等于内容常驻。Windows 剪贴板由系统管理，不自动清空，不声称能控制剪贴板历史、分页文件或安全擦内存。

去敏诊断可由用户主动复制，只含版本、系统、错误类型与去敏内部堆栈，不含图片/OCR/用户路径；不是日志文件导出。应用 P-10 诊断只记运行元信息，不记 Base64、完整 URL 或正文。产品不依赖旧 TextSnap/开发源码目录或 Python。

性能要同机同图量加载、常驻/峰值内存、普通与 4K 识别耗时，不拿历史 Python 数字宣称更快，不自定硬延迟或零资源竞争。与文档并用速度可能受 CPU/内存影响。

## 识别与二维布局的确定规则 {#layout}

O-23～O-28 及附录 B 是可重复行为基准，不是用户调参面板。当前采用指定新版 Xberg 行为，冻结 TextSnap 仅历史对照。

- CPU 10 个算子内线程、顺序执行；只指定 det/rec，关闭额外方向/去畸变模型。选区任一边大于 1216 时瓦片最大 1216×1216、步长 1088（重叠 128），先 y 后 x，尾部裁到边界不回移。
- 检测 `max/1216`、阈值 0.3、box 0.5、unclip 1.5。辅助水平细线高≤4、跨度≥48、上下 4 像素隔离且未覆盖者可生成 0.5 候选；全框映射回原选区，不用整体缩小大图替代。
- 先接缝合并再去重，从原图重裁，不拼已识别文字。重复 IoU≥0.4 或交集/小面积≥0.6，传递分组；优先离内部边缘更远、分数更高。边缘≤2 像素视接触；仅水平相邻重叠瓦片、垂直重叠≥0.6、高比≥0.65 与规定距离才合并，不能把分栏当接缝。合并后重算并集边缘、取最大检测分，候选按顶部/左边/瓦片序排序。
- 凸、四顶点互异且非零面积才透视裁剪；宽高取对边较长者，半偶舍入，任边<2 失败，三次插值和边界复制。识别 batch 8；先原方向，高宽比>1.3 加试 90/270，否则首试<0.5 加试 180，不对全部框四向重试。平分先非空，再 0/180/90/270。只保留非空且分数≥0.7，结构化与布局同步过滤，不语言补全或繁简替换。
- 小裁剪高<20 先两倍三次插值；归一化到 48 高时原高≤32 用三次、其他线性。未钳识别宽度≥6400 按与 3200 比例分段，文本按段拼接、分数按文本长度加权（空段权重 1，全空 0）。
- 原向非空、宽高比≤20 且同行最左且扩展区无框时，可左扩 1.5 倍框高重试补标点；仅接受严格更长、原文在端部、新增至少 2 个非空白且全部为规定标点、分数不低于原−0.02。密集代码高20～40、宽高比≥12、首试≥40字、至少3竖线且有 `::` 或至少2下划线，可横向1.5倍 Lanczos4 重试；按更长或同长更高分及−0.02门槛决定替换，不做文字纠错。
- 行聚类垂直重叠≥0.45 或基线差≤正文中位高0.5；平局看重叠、基线差，行参数取成员中位数，行按中心 y/最左 x，行内从左到右。跨栏 y 近仍同行，以空格留栏距，不改阅读顺序。
- 网格按框宽/Unicode 显示单元的截尾中位数，W/F宽字符2、普通1、组合0；控制字符先空格。≥5样本两端去 max(1,floor(n×0.1))，无值回退1。x 使用 floor(x+0.5)，同时满足绝对位置/实际间隔/不重叠，后框碰撞右移。
- y 按相邻正基线差，剔除大于正文高3倍的间隔后取截尾中位，缺值用高1.4倍再缺用1；逐间隙推进 max(1,floor(差/行距+0.5))，不从首行累计舍入。只裁公共上/左边距，保留内部空格/空行/缩进，去行尾空格、不补终末换行。

## 怎样理解验收覆盖 {#acceptance}

附录 C 保留纯逻辑严格文本比较、无头真实 OCR、真实桌面热键/托盘到框选/复制、后台关窗/重开/异常、100/125/150/200% DPI 与负原点显示器、两种实际分发/缺损/迁移/隐私及跨场景并用。

合成清晰高对比样本目标不丢行、接缝无重复截断、字符错误率≤2%、布局锚点偏差≤一个半角或一行；固定模型达不到时报告基线，不偷换模型或放宽期望。当前 medium 检测与冻结 small 检测不是同模型后端对照；文本/布局/耗时差异逐项报告，浮点逐位不同本身不是用户问题。

升级未完成迁移时，热键、jchocr、文档仍应共同使用旧有效目录，不各自切包内源。安装包 PATH 调用与便携直接调用也需真实验证。旧“299 项、3 跳过”、Slint 测试后端和模拟引擎都不能当现版桌面/固定模型验收；本站没有执行这些产品测试。全局关系仍按 H-03/P-02 独立性、P-03/P-09 网络、P-05/E-04 交付、P-06/S-07/U-10 导出边界、R-01 独立持久设置、U-01/U-05/U-08 窗口及 U-09 关窗区分处理。

# CodeAgent：当前用户 Token 自动维护 {#codeagent}

这是独立本地凭据维护工具，不是代码 Agent 对话入口，不调用模型服务、PowerShell 或网络。只有已经使用相应 CodeAgent 登录并具备本地凭据的用户才需要开启；JchTools 不创建账号、不提供 Token，也不要求把凭据复制给同事。

## 前置条件与第一次设置 {#behavior}

CA-01～CA-04：在原 CodeAgent 的正常流程完成当前 Windows 用户登录后，打开 JchTools 左侧“开发 → CodeAgent”。程序读取标准用户相对位置 `%USERPROFILE%\.cac\.credentials.json` 中的 `idaasOAuth.xAuthToken`，Base64 解码后以 Windows CurrentUser DPAPI 解密（附加熵 NULL），按 UTF-8 解析。

这不是一个可跨用户/机器任意复制的通用密码格式。请让原应用生成凭据，不要手填假密文、从别人电脑拷文件或在公开问题中上传原件；无法读取/解密时本工具不会要求用户提供明文。

解密后的值仅写入当前用户环境注册表 `HKCU\Environment\JCH_CODEAGENT3_X_AUTH_TOKEN`，类型 REG_SZ；值相同不写，变化立即更新。该标准键名是接口说明，不是本站披露的真实 Token；不要用注册表截图或控制台打印它验证。

默认每 60 秒检查。需要调整时在页面输入正整数秒并保存；间隔持久保存，后台采用新值。程序维护的是用户环境注册表，不承诺强制刷新已经运行的其他进程环境，既有程序的重新读取行为取决于其自身实现。

## 页面与独立后台 {#lifecycle}

CA-05、CA-06：打开页面自动启动或连接单实例后台，不需额外命令。页面显示后台是否运行、最近检查时间、去敏检查结果与间隔，**不显示 Token**。关闭 GUI 后继续检查，不属于文件任务停止、截图/Xberg 托盘退出或模型服务页退出范围。

共享 SQLite 暂时不可用时后台保留最后有效间隔继续维护，不能释放单例锁形成第二个实例；存储恢复再补写最新安全状态。状态记录/日志/控制台/错误都不能包含明文 Token。后台运行状态不是模型认证成功或远端接口可用的证明，本功能根本不联网验证它。

## 读取失败怎么处理 {#failure}

CA-07：文件不存在、字段无效、Base64/DPAPI/UTF-8 解密失败，只报告去敏原因，**保留已有注册表 Token**，按间隔继续检查。不要为了消除错误先清空有效键，也不要把明文放进错误信息。确认登录的是同一 Windows 用户，回原 CodeAgent 正常更新登录状态，再查看下一轮安全结果。

如果间隔输入无效，应修正为正整数；不要猜测一个新 Token 或用其他用户凭据覆盖。日志用于本地排障，无需上传凭据文件、密文或注册表内容。

## 升级和卸载 {#maintenance}

CA-08：安装器在升级替换或卸载删除文件前，经内部维护入口请求**本应用拥有的** CodeAgent 后台自然退出，等待释放程序镜像与单实例锁。不能完成则明确阻止此次替换/卸载，不自动强杀其他进程，也不能把部分替换当成功。

这是安装维护专用行为，不是新增用户 CLI；普通关闭 GUI 仍不会停后台。维护退出不删除原凭据文件或已有注册表 Token。便携目录移动与文件清理也不能被理解为授权清理其他用户资料。

## 验收应看安全结果而不是秘密 {#acceptance}

轻量验收使用隔离合成密文/注册表/安装位置：CurrentUser DPAPI 恢复合成 UTF-8，错误密文不改旧值，REG_SZ 更新且相同值不重写；真实内部后台证明单例、持久间隔、GUI 退出继续检查、状态查询并发及 SQLite 暂时争用恢复；页面仅安全状态，维护退出后旧镜像可替换/删除，失败不假报安装完成。

这些检查不能通过打印 Token 来证明，也不以网站来源覆盖替代产品测试。本次文档工作没有读取任何真实凭据/注册表值、没有启动后台或执行真实桌面验收；实际使用仍以对应版本证据为准。

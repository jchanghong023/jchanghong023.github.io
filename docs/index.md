# 研发工具文档 {#overview}

这里是同事使用 **OMP、OmpCode 和 JchTools** 的中文手册。先根据工作方式选择工具，再沿对应项目的“安装与快速开始”完成准备；遇到限制或错误时，查阅同一项目的专题页。

## 从哪个工具开始 {#choose}

| 工具     | 适合的工作方式                                                      | 阅读入口                                                                  |
| -------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| OMP      | 在终端中与代码 Agent 协作，使用工具、Skill、知识索引和多 Agent 编排 | [OMP 概览](/omp/) · [安装与快速开始](/omp/getting-started)                |
| OmpCode  | 使用桌面或 Web 界面与 OMP 核心协作，管理会话、模型及输入            | [OmpCode 概览](/ompcode/) · [安装与快速开始](/ompcode/getting-started)    |
| JchTools | 在 Windows 本地完成文件处理、转 Markdown、截图 OCR 及辅助服务       | [JchTools 概览](/jchtools/) · [安装与快速开始](/jchtools/getting-started) |

不确定时，从[选择工具与首次使用](/getting-started)开始。三个产品不是同一个安装包，下载、配置和数据目录应分别按对应指南处理。

## 如何查找说明 {#reading}

- 左侧文档目录按项目分组，右侧目录定位当前页章节；窄屏使用“文档目录”按钮。
- 顶部搜索在本站内容中检索，也可以输入需求编号查找追溯说明。
- 每个项目的概览介绍支持范围；快速开始介绍安装与最短操作链；专题页介绍功能、失败处理和验收边界。
- 页面底部可查看文档更新时间或进入网站源码编辑。产品需求原文入口集中在[来源与完整覆盖](/coverage)。

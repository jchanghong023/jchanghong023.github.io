# 长会话、文件查找与性能排查 {#overview}

## 优化不能丢内容 {#invariants}

性能策略必须保持对话全文、工具结果、任务状态、历史分页和订阅水位一致。桌面连续帧与 Web 快照/缺口恢复仍交付相同最终事实，不能缩短历史、静默丢帧或关日志来冒充提速。

流式可内部缓冲，但 snapshot、历史范围和完成态要包含当前 seq 的完整文本；同帧多个 delta 只发布一份不可变快照，不改旧快照。代码高亮、分组/工具查找索引和 UI 视图缓存只是可淘汰派生数据，不是历史权威源。

## 用户能观察到的行为 {#usage}

- 对话查找立即回显输入，昂贵匹配/历史读取在稳定 150ms 后执行；清空、关闭或换范围使旧查询失效，不让旧高亮回来。
- 时间线计时只更新运行轮，单轮流式不重算所有旧轮；历史前插、替换、删除后仍保持完整顺序。
- 思考折叠显示最新摘要，展开可看全文；代码流式保留组件身份，复制、主题与最终高亮都使用完整最新内容，不以首尾两行判断正确。
- 设置页可延迟加载，打开时必须可用；终端、导航和当前会话不能因开关设置丢失。
- 「打开方式」先用静态路径，异步兜底探测编辑器，不在主线程同步等外部命令。
- 会话 A 慢历史不能阻塞 B 的停止和实时帧。A 同订阅 ACK 必须先于首帧，后续定时帧仍按生成顺序发出，不等整次读取结束。

遇到卡顿，先区分流式渲染、冷历史读取、查找、文件扫描或日志写盘，不通过清空历史规避问题。

## 文件 mention 与扫描 {#files}

`@` 索引与 ignore 缓存由 Host 按 workspace identity 和真实 rootPath 持有。同版本/同 workspace 的在途补扫复用，多个无命中前缀不逐字符重扫；显式刷新、规则变化或下一轮仍可发现新文件。清空并重新打开 mention 会同步开启新轮，旧空查询回包不能吞掉新轮补扫。

ignore 读取临时失败的降级 matcher 只服务本次请求，不能绑到成功 stat 指纹长期缓存。读取恢复后排除规则应重新生效；同路径不同 identity 与旧代扫描不能污染当前索引。

仅 Linux offline 扫描最多八路动态目录读取：根目录还未枚举完时其他槽不能永久退出；首错停止接纳，等待在途关闭后拒绝，避免后台继续写索引。普通模式及 Windows 同名环境变量仍走原路径，ignore、符号链接、排序和 TTL 规则不变。此并发上限不是目标网络盘性能承诺。

## 输出持久化与传输 {#pipeline}

```text
OMP 事件 → 会话 seq/rows 投影 → 单次编码与必要分片
  → 桌面连续 / Web 可重放交付 → UI 稳定选择器与派生缓存
```

原生 custom 输出按同会话、类型、正文与原生时间戳判断重复；同文不同时间保留。首次建立去重视图后只读取追加范围，文件替换/截短失效，不为每条输出重扫全部 JSONL。

连接未发送字节有上限，饱和不能让桌面静默丢帧；Web 可按同一水位补发/快照。关闭 DEBUG 时不能为日志重复编码帧。Main 异步日志避免同步文件 IO 阻塞，退出排空有界，见[日志](./logging)。

## 测量与结论边界 {#evidence}

维护时以同一大目录/长历史、相同输入和配置对比前后耗时与内存，记录草稿写入次数、目录扫描次数、历史遍历和完整结果；缓存暖样本不能叫冷启动。代码、高亮和冷恢复要比较完整内容与顺序，不只比 DOM 存在或修改 props。

源文档含 Windows 的真实 GLM/代码/mentions 与受控八路扫描记录；33 目录等本地对比只证明该调度/隔离，不是 NFS、CentOS、原生 IME/失焦、真实 Web GUI 或上传全链路实测。性能改动不改协议能力或用户配置，未测部分不能用理论收益补上。本站未跑基准或产品测试。

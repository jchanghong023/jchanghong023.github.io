# CentOS 7 无 GPU 显示策略 {#overview}

## 哪些地方会不同 {#scope}

CentOS 7 发布构建标记 `__OMPCODE_CENTOS7_DESKTOP__` 启用减动效与流式正文显示合批；它与 `OMP_OFFLINE` 无关，普通联网 CentOS 也采用该显示策略。Windows 与 Web 不因此减少动画，界面元素、入口及功能保持一致，不是另一个轻量产品。

无 GPU/远程 X 软件绘制的真实收益取决于目标环境。本地或 Windows 结果不能证明目标机器滚动/打字已经流畅，也不承诺具体帧率。

## 动画和正文如何呈现 {#rendering}

根视觉策略缩短 CSS 动画/过渡到完成态，停用背景模糊和平滑滚动，同时保留结束事件、提示、布局和功能；已有 JS 动画读取系统减少动态偏好。

正文只缓冲**显示文本**，最多每 100ms 发布最新累计值，Markdown/引用/图片/数学预处理消费合批结果。首段、完成、中止、正文替换或身份切换立即显示并取消旧计时器，卸载不留延迟写入。

会话原始投影、传输 seq、保存与复制都不被合批删减；不能以展示减少更新为理由截断原始内容。最终全文、展开思考和代码复制仍应与记录一致。

## 异步日志与退出 {#logging}

Main 是唯一文件队列所有者，同文件连续记录合并，按顺序串行异步写盘，目录操作也异步。参考合批窗口 25ms、排队上限 4MiB（不含正写入批次）使用显式常量；超载计数后报告，不无限堆积/重试，磁盘错误不传回业务。

此 writer 也用于 Windows，不再保留第二条同步写入路径。普通与 offline 模式统一遵循 `JCH_LOG_LEVEL`，DEBUG 不因平台/生产构建关闭；连接进度和用户可见结果不是诊断日志，不能被过滤吞掉。

正常退出在 Host 清理后/最终退出前共用最多一秒排空预算，不是每次调用再等一秒；强杀、磁盘错误、超时不保证写盘。轮转/保留与进程隔离见[日志指南](./logging)。

## 如何判断改善而没有退化 {#evidence}

维护验证应在同输入下比较最终全文、发布次数、切换/卸载残留，覆盖慢磁盘、同文件合批、跨日顺序、过载、失败与 flush。Windows 构建不应意外减动画，构建标记不能改变 reporter、模型目录或状态订阅。

当前测试范围仅 Windows 适用共享断言，不进入 CentOS/Linux/WSL、VM 或远程 X 专项。源文档早期同步 mkdir 缺口已按当前异步源码纠正，但这不是目标机器测量；取消专项测试也不代表 CentOS 性能验收。本站未做产品运行或性能基准。

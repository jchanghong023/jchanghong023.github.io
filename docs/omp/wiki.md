# Wiki：让 OMP 查企业资料 {#wiki-guide}

把规范、接口说明、设计文档等导入 Wiki，以后直接提问，让 OMP 查资料并给出出处。**Wiki 查文档，[Repo](/omp/repo)查代码。**

## 第一次怎么准备 {#import}

1. 准备好一个 **Markdown 文件夹**。PDF、Word 等先转成 Markdown，可用 [JchTools](/jchtools/)。图片和附件不会自动变成可检索的文字。
2. 在 OMP 输入框输入 `/wiki`，按 **n** 新建。
3. 给这批资料起个名字，填写文件夹路径，核对后按 **Enter** 导入。
4. 等待完成，看到资料出现在列表中，就可以使用了。

请一直使用平时的 OMP 启动方式，避免换账号或换配置后找不到刚导入的资料。

## 平时怎么查 {#ask}

回到普通对话，直接说：

```text
查 Wiki，说明这个接口有哪些使用限制，并给出资料出处。没有查到的内容不要猜。
```

也可以输入 `/wiki`，选中一批资料，按 **/** 输入关键词，按 **Enter** 搜索。

## 文档更新了怎么办 {#update}

Wiki **不会自动跟随原文更新**。准备好新资料后，在 `/wiki` 列表选中旧资料，按 **d**、再按 **y** 删除，然后按 **n** 重新导入。

这里删除的是知识库记录，不会删除原文件；重新导入成功前，这批资料暂时查不到。

## 两点提醒 {#notes}

- 只导入有权使用的资料，并使用公司允许的模型；让 AI 回答时，相关文档内容可能发送给所选模型。
- 红区 Linux 使用内存保存运行数据，重启后不会自动恢复。重要资料保留原件，数据备份说明见[红区运行提醒](/omp/features#shm)。

# Repo：让 OMP 更方便地找代码 {#repo-guide}

接手陌生项目、找某个功能或排查问题时，可以先为项目建立代码索引，再让 OMP 定位相关文件、阅读源码。**不用记查询参数，直接描述任务即可。**

## 第一次怎么用 {#start}

1. 在目标项目目录启动 OMP，输入 `/repo`。
2. 看清面板显示的项目路径，确认没有选错项目。
3. 按 **b** 建立索引，再按 **y** 确认，等待完成。
4. 按 **Esc** 回到对话，直接提出任务。

例如：

```text
用 Repo 找到这个项目读取配置的代码，阅读相关文件，解释从哪里开始、出错时怎么处理。先不要修改。
```

也可以让它找某个 Python 类或函数。查企业规范、设计说明等文档，请用 [Wiki](/omp/wiki)。

## 代码改了怎么办 {#update}

OMP 自己修改的文件通常会自动维护。**切换分支、用外部编辑器改代码或批量改文件后**，打开 `/repo`，按 **u** 更新。

如果提示索引损坏，或升级后仍找不到应有的 Python 定义，可按 **r**、再按 **y** 重建。重建比更新更费时，不需要每次都做。

## 需要注意什么 {#notes}

- 建立或更新很久不想等了，可以按 **c** 取消。
- 出现未核对或失败提示时，先处理问题，不要把旧结果当成最新代码。
- Repo 帮你找位置，不代替实际阅读和测试。没找到时，可以让 OMP 直接查源码；没建索引也不影响普通开发。
- 索引含项目代码，按公司要求保存，不要随意对外分享。
